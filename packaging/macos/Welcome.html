Tipp10 installieren

Diese inoffizielle Version von Tipp10 ist fuer Apple Silicon und macOS 26 oder neuer vorgesehen.

Das Programm wird nur fuer Ihr Benutzerkonto installiert, unter ~/Applications/Tipp10/tipp10.app.

Die Datenbank tipp10v2.db wird beim ersten Start neben dem Programm angelegt. Vorhandene Datenbanken in diesem Ordner bleiben erhalten. Das Paket enthaelt nur die originalen Startlektionen.

Nach der Installation finden Sie Tipp10 im Ordner Applications in Ihrem Benutzerordner. Wenn Sie das Programm spaeter verschieben, verschieben Sie auch die Datenbank.

Wenn Sie Ihre eigenen Lektionen und Trainingsergebnisse aufbewahren möchten, sichern Sie die Datei tipp10v2.db gelegentlich und vor dem Import einer anderen Datenbank.
